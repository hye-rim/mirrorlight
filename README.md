# 🔦 거울 빛

레이저가 **모든 수정**에 닿도록 **거울을 눌러서 돌리는** 퍼즐입니다. 레벨 36개, 세계 5개.

## 하는 법
- 거울(/ 또는 \\)을 누르면 방향이 바뀝니다. 빨간 빛이 수정에 닿으면 노랗게 빛나요.
- 수정이 **모두** 빛나면 한 판 끝! 가장 적게 돌릴수록 별이 많아요 (최소 횟수 이하 ★★★, 2번까지 더 ★★, 그 이상 ★).
- **회색 거울**은 못 돌리고, **보라색 분할 거울**은 빛을 곧게 보내면서 한쪽으로도 보내요.
- **벽**과 **수정**에서는 빛이 멈춰요.
- 되돌리기 · 처음으로 · 💡힌트(쓰면 별 최대 2개). 키보드: Z 되돌리기, R 처음으로, H 힌트.
- 앞 레벨을 풀어야 다음 레벨이 열려요.

## 세계
1. 빛의 시작 — 거울 1~3개, 5×5
2. 거울 숲 — 못 돌리는 거울과 가짜 거울, 6×6
3. 갈라지는 빛 — 분할 거울, 수정 여러 개, 7×7
4. 거울 미로 — 벽이 많은 8×8
5. 빛의 궁전 — 9×9, 수정 4개

## 만든 방식
- `logic.js` — DOM 없는 규칙 (`LOGIC_ML`): 빛 따라가기(`trace`), 풀이 찾기(`solve`), 한 판 상태(`newGame`/`flip`/`undo`/`hint`/`stars`).
- `levels.js` — 레벨 36개를 **고정 난수(시드)** 로 만듭니다. 빛이 갈 길을 먼저 그린 뒤 거울 방향을 흐트러뜨려서 **반드시 풀 수 있고**, 풀이기로 최소 횟수(par)를 확인합니다.
- `game.js` / `index.html` — 화면, 입력, 소리. 저장: `mlStars`(레벨별 별), `mlBest`(모은 별 합계), `mlSound`.
- 시험: `node --test` (디렉터리). 36개 레벨 전부 풀 수 있는지, par 가 진짜 최소인지, 난이도 상승 등을 확인합니다.
